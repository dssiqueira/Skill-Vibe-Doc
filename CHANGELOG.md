# Changelog

## 3.0.0 (2026-10-11)

- O Vibe Doc virou uma Agent Skill com quatro modos: criar, atualizar, revisar e migrar.
- `DESIGN.md` na raiz, no padrão aberto do Google, assume a parte visual que ficava no `layout.md`.
- `layout.md` virou `docs/fluxos.md`, só com telas, fluxos e estados.
- Novo `AGENTS.md` como porta de entrada única para qualquer agente.
- Novo `docs/decisoes.md` para decisões técnicas, com nível de autonomia quando há IA.
- `contexto.md` ganhou critério de sucesso e critério de morte.
- Os cinco exemplos foram refeitos no formato novo, com DESIGN.md validado pelo lint oficial.

## 2.0.0

- `create-vibedoc`: CLI no npm que gera os seis arquivos e as regras por ferramenta (Cursor, Windsurf, Claude Code, Bolt, Lovable, Copilot, Codex, Kiro e Antigravity), em 10 idiomas.
